# Acacia Dental Store — GitHub Pages V2

## رفع الموقع
ارفع جميع الملفات والمجلدات كما هي إلى مستودع GitHub Pages:

- `index.html`
- `css/style.css`
- `js/app.js`
- `data/products.json`
- `images/placeholder.svg`
- `images/products/`

## مهم
ملف `products.json` هو مصدر بيانات المنتجات. لا تحذف أو تعيد تسمية مجلد `data`.

## الصور
المنتجات الحالية تشير إلى مسارات `images/products/ac-xxx.webp`.
ضع صورة كل منتج في المسار المطابق، أو عدّل حقل `image` في `products.json`.
